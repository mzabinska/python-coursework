# Python Coursework

Selected Python coursework demonstrating core Python concepts and object-oriented programming.

# Economic Report

File: `economic_report.py`

A small economic reporting application that demonstrates:

- type hints
- string processing
- `match` statements
- default and named arguments
- `*args`
- nested functions
- generators and iterators
- conditional expressions
- file handling

The program calculates gross prices, discounts, revenues and margin categories for a set of products and generates a text report.

# Inventory Management System

File: `inventory_system.py`

An object-oriented inventory management application demonstrating:

- abstract base classes
- inheritance
- polymorphism
- encapsulation
- abstract methods
- object composition
- inventory operations

The program supports different product types, deliveries, stock withdrawals and inventory value reporting.
